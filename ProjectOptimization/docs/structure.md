# 目录结构说明

## 根目录

- `src/`：优化版代码副本
- `data/`：本地数据集副本
- `models/`：模型分类仓库
- `configs/`：训练/推理配置
- `scripts/`：可执行脚本入口
- `outputs/`：训练与推理产物
- `logs/`：运行日志与环境检查日志
- `ui/qt5/`：Qt5 可视化接口占位
- `docs/`：项目文档
- `archives/`：归档文件

## 模型分类目录

- `models/yolo/pretrained`
- `models/yolo/custom`
- `models/stgcn/pretrained`
- `models/stgcn/legacy`
- `models/stgcn/out3`
